Discipline, portable version

Because this folder (Discipline-data) is next to the program, Discipline keeps all its own data in
here: its working copy of your data and its settings. Copy or move the program together with this
folder. Delete or rename the folder to use the data of an installed Discipline instead.

A backup file (if you chose one in the settings) stays wherever you chose to keep it.

On Linux, Discipline uses the system's WebKitGTK 4.1, which most desktops have. If it doesn't start,
install it: webkit2gtk-4.1 on Arch, libwebkit2gtk-4.1-0 on Debian/Ubuntu, webkit2gtk4.1 on Fedora.
